1. 이용 목적

Quiet Moments KO는 채널 소유자 본인이 자신의 YouTube 채널(성경묵상)에 성경 낭독 영상, 자막, 썸네일, 재생목록을 업로드하고 공개 일정을 관리하기 위한 개인/내부 전용 도구입니다. 외부 일반 사용자를 대상으로 서비스를 제공하지 않습니다.

2. 접근하는 Google/YouTube 데이터

사용자의 명시적 OAuth 동의를 통해 아래 YouTube Data API v3 권한만을 사용합니다.

  • youtube.upload: 본인 채널에 동영상 업로드
  • youtube: 본인 채널의 재생목록 관리 및 영상 공개 상태 변경
  • youtube.force-ssl: 본인 영상의 자막(captions) 업로드

3. 데이터 보관 및 제3자 제공 금지

인증 토큰은 채널 소유자의 로컬 실행 환경에만 암호화/제한 권한으로 보관되며, 수집된 어떠한 Google/YouTube 사용자 데이터도 외부 서버로 전송·판매·공유·제공하지 않습니다.

Privacy Policy (English)

Quiet Moments KO is a personal automation tool used solely by the channel owner to upload and manage scripture reading videos, captions, thumbnails, and playlists on the owner's own YouTube channel.

OAuth credentials and tokens are stored strictly on the owner's local machine. This application does not collect, store, sell, or share any personal or Google user data with third parties, and uses authorized YouTube API data strictly for channel self-management in compliance with the Google API Services User Data Policy.
